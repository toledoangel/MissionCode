2Variables y física: ¿qué tan alto llegará?

Una variable guarda un valor que puede cambiar. La altura de un cohete que acelera desde el reposo se calcula con la función altura = ½ × aceleración × tiempo². Mueve las variables y encuentra los valores para llegar a la órbita correcta: entre 113 km y 141.75 km.

altura = ½ × 28 × 90²
113,400 m = 113.4 km 
def calcular_altura(aceleracion, tiempo):
    altura = 0.5 * aceleracion * tiempo**2
    return altura

aceleracion = 28   # m/s²
tiempo = 90        # segundos
altura = calcular_altura(aceleracion, tiempo)
